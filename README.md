
# Restaurant-Bestellsystem

## Beschreibung

Das Projekt ist ein einfaches Restaurant-Bestellsystem, das mit Python umgesetzt wurde. Es ermöglicht das Erstellen und Verwalten von Kunden, Gerichten und Bestellungen sowie die Berechnung des Gesamtpreises.

**Verwendete Klassen:**
- Kunde
- Gericht
- Pizza
- Getraenk
- Pasta
- Bestellung

## Installation und Ausführung

1. Das Projekt über GitHub mit Code → Download ZIP herunterladen.
2. Die ZIP-Datei entpacken.
3. Den Projektordner in Visual Studio Code öffnen.

Der Programmcode befindet sich in `src/klassen.py`.

## Tests

Die Tests befinden sich im Ordner `Tests` und können auf zwei Arten ausgeführt werden:

- Über den Testing-Tab in Visual Studio Code.
- Über das Terminal mit folgenden Befehlen:

```bash
python -m pip install pytest
python -m pytest Tests/
```
